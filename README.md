Selected hands-on automation exercises completed during my Playwright and TypeScript training. This repository demonstrates practical experience in creating, executing, debugging, and organizing automated browser tests.

## Skills Practiced

Playwright · TypeScript · Locators · Assertions · Hooks · Test Tagging · Data-Driven Testing · JSON/CSV · Page Object Model · Allure ·Trace Viewer

## Practice Websites

LambdaTest E-commerce Playground for e-commerce UI automation exercises.
Art of Testing Sample Site for inputs, buttons, radio buttons, checkboxes, dropdowns, and other web-element interactions.

These are public practice applications. I did not develop these websites. My work focused on creating, executing, and debugging Playwright automation tests against them.
